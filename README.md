# demrender.com

The website of DemRender, the music visualizer studio for Windows: a static page served by GitHub Pages
(custom domain in `CNAME`). The Download buttons read the newest installer from
`dagafitei72-cpu/demrender-releases` through the GitHub API, so a new release needs no change here.

The clips in `assets/media` were exported from DemRender itself, on its own synthesized demo tracks.
