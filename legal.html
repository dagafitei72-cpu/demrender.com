Privacy

The app. DemRender works offline. It has no account, no analytics and no tracking. Your songs, pictures and projects are read from and saved to your own computer only. To find updates, it asks GitHub whether a newer version of DemRender has been published — GitHub sees that request like any visit to a web page (your IP address), and nothing else is sent.

This website. demrender.com is hosted on GitHub Pages and uses no cookies, no analytics and no third-party scripts. To show the newest version on the Download button, your browser asks GitHub's public API for the latest release. GitHub's own privacy statement covers both.

Email. If you write to contact@demrender.com, we use your message and address only to answer you.
